# LINCE GUARD — Hackatón LinceCode 2026

Aplicación Android de pruebas para lectura continua de credenciales QR y códigos de barras mediante CameraX y ML Kit, conectada por red local al servidor LINCE ACCESS.

**Aviso:** prototipo educativo. Usar solo cuentas y registros ficticios; el servidor de desarrollo utiliza HTTP.

## Compilación automática

Abre la pestaña **Actions**, selecciona **LINCE GUARD - Compilar APK Android** y descarga el artefacto `LINCE_GUARD_APK_ANDROID` cuando la ejecución termine correctamente.

La aplicación necesita el servidor Node.js de LINCE ACCESS V0.3.1 en la laptop. En el teléfono, escribe la dirección local correspondiente (por ejemplo `http://192.168.137.1:3000` cuando se comparte la red desde Windows).

**Fuente:** versión 0.3.1. El ZIP de código fuente se incluye en el repositorio para que el flujo automático lo extraiga antes de compilar.
